## Short description

OSS Maintainer Desk is a dependency-free, local-first dashboard that helps open source maintainers turn GitHub issue and pull request queues into a weekly maintainer brief. It flags stale issues, unlabeled work, review bottlenecks, unassigned work, and release candidates, then exports an editable Markdown report and AI prompt.

## Why it helps the open source community

Maintainers often lose time deciding what needs attention first. This tool gives small and medium-sized OSS projects a lightweight triage workflow without requiring a paid SaaS product, database, or hosted backend. It can be hosted on GitHub Pages and used directly by contributors, maintainers, or project leads.

## Current status

New project. The initial release includes a static browser app, GitHub API integration, sample data, triage heuristics, Markdown export, privacy documentation, contribution guidelines, and an MIT license.

## How OpenAI credits would be used

Credits would be used to add an optional server-side workflow that converts weekly GitHub activity into higher-quality maintainer summaries, release note drafts, and contributor-friendly next-action lists. The integration should remain opt-in and transparent so maintainers can review repository data before sending it to an AI model.
